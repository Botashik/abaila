# Abaila

**Abaila** (“Абайла” means “be careful” in Kazakh) is a demo app that warns people, mainly older people, about scam phone calls. It works in Kazakh, Russian and English.

**Author:** Botakoz Berikkyzy, Astana IT University (Technology Entrepreneurship, Assignment 5: MVP)

**Live demo:** https://botashik.github.io/abaila/

## What the demo shows

- A warning during a scam call, with the scam risk (%) and a voice warning
- Test calls: fake bank, “your relative is in trouble”, fake prize, fake Kazakhtelecom, a normal call from family, and your own words
- Alerts to a family member
- Saved risky calls (only calls with more than 50% risk)
- Check a phone number or an SMS, and report a scam
- Monthly report and plans

## Important

This is a demo. It does not listen to real phone calls yet. The test calls show how the app will work.

You can install it on your phone: open the link, then choose **Add to Home Screen**.

The demo code was created with the help of Claude AI.
